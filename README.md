# chim
'chim' is my codename for my console. i programmed it in c++ using SDL3. i hope in the future i can continue expanding on it to be modular because right now its not.
# Functionality
BACKTICK - Open and close the console window
TAB - Autocomplete the current input
PAGEUP - Scroll up in the console output
PAGEDOWN - Scroll down in the console output
